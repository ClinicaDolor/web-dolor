- **Comprobado:** observable en rutas, controladores, modelos, vistas o configuración.
- **Inferido:** comportamiento deducido de varias piezas de código y pendiente de validación con el equipo clínico.
- **Pendiente:** no verificable únicamente desde este repositorio.
